# Component Comparison Playground

A visual comparison of legacy and migrated chat-library components using one shared AI conversation.

## Language

**Shared conversation**:
One sequence of prompts, responses and submitted actions viewed through both libraries.
_Avoid_: Two chats

**Comparison response**:
One complete AI response presented by both libraries as it arrives.
_Avoid_: Split response, two generations

**Comparison pane**:
One library's presentation of the shared conversation, with its own visible rendering errors.

**Replay**:
A repeat presentation of a retained response without another AI request.

**Draft input**:
Unsubmitted form input belonging to one comparison pane, independent of the other pane.
