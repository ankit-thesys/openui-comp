# Production Component Packages

The supported component building blocks and chat compositions offered to consumers.

## Language

**React components**:
The migrated reusable component package, named `@openuidev/react-components`.
_Avoid_: React UI core (except when describing the previous package name)

**Chat kit**:
The chat-specific components and library compositions supplied by `@openuidev/kits`.

**Supported building block**:
A component or composition part intended for consumers to use directly, together
with the types needed to use its public contract.

**Implementation internal**:
A helper, style definition or hook used to implement supported building blocks,
without an intended consumer-facing contract. A name alone does not establish this status.
